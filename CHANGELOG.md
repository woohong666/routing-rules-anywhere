# Changelog

All notable changes to this repository will be documented here.

## [1.0.1] - 2026-10-11

### Changed
- Expanded `README.md` into a practical Anywhere usage guide.
- Switched documentation to a subscription-first workflow.
- Added copyable `.arrs` examples and the full current Meta template.
- Documented Anywhere rule priority and Built-in vs User conflicts.
- Added the limitation that a Private GitHub raw URL cannot be used as an anonymous Anywhere subscription source.
- Added a recommended Private source → public read-only mirror → Anywhere subscription workflow.

## [1.0.0] - 2026-10-11

### Added
- Initial Anywhere-only private routing rules repository.
- Added `anywhere/Meta-Fixed.arrs`.
- Added repository usage and security notes.
